# Research queue

The loop that moves us toward trading profitably. One hypothesis per cycle, run by Codex (GPT-6.1-Sol, high effort), reviewed by Claude.
Each cycle: pick the top open item → pre-register it in RUNBOOK.md (rule, data, pass mark, prediction) → design on older data → confirm once on data it
never touched → write the result and **one lesson** below → re-rank the queue. "No edge" is a valid result and still earns a lesson.

Standing rules: paper only; the frozen panic-buy rule and the live guards don't change without a passed test and the user's yes; costs are always
Zerodha charges + slippage by tier; survivorship-free data (NSE bhavcopy) wherever the test spans years; the bar for confirmation rises with every
rule sent to it (t ≥ 1 + 0.5 × earlier confirmations; currently 2.5).
