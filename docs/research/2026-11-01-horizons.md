# Fixed panic-rule horizon ladder

H17 cleaned daily reconstruction, 1 November 2016 through 31 October 2026. ₹10,000 fixed allocation, whole shares, 3% stop and H17 costs. No compounding or rule changes.

Full half-open calendar windows only; monthly starts for years, every 7 days from 2016-11-01 for months, daily starts for weeks. Net percentiles include quiet windows.

Overlapping windows reuse observations. Strict and loose are separate frozen experiments.

The daily open/low/close model cannot establish executable returns after a 09:20 decision. Quiet windows are retained as zero; positivity uses only windows with funded trades. Qualifying mornings count the NIFTY gate even if no pick can be funded.

## Lesson

Sparse weeks often contain no trade. The nested horizons describe the same fixed rule and do not create fresh confirmation or a reason to select between strict and loose.
